# ARCANA Privacy Policy

Last updated: 2026-11-23

ARCANA is a personal tarot reading application operated by an individual developer for a small group of friends.

## Data we collect

- QQ email address used to sign in
- Encrypted API keys configured by the user
- Session tokens and basic account timestamps
- Limited technical logs needed to operate and debug the service

## How we use it

- Send a login verification code to the QQ email address
- Keep the user signed in
- Store and use the API key that the user chooses for tarot readings
- Diagnose errors and protect the service from abuse

## Email

ARCANA sends transactional login verification emails only. It does not send newsletters, marketing messages, or promotional email.

## Sharing

We do not sell, rent, or trade personal data. Data may be processed by infrastructure providers used to run the service, including Neon (PostgreSQL hosting), Render (application hosting), and Mailjet (transactional email delivery). These providers process data only to provide those services.

## Retention

Account data is kept while the account is active. A user may request deletion by opening an issue at:

https://github.com/youth123456789/arcana-tarot/issues

## Security

API keys are encrypted before storage using AES-256-GCM. Session tokens are stored as SHA-256 hashes. No method of storage or transmission is completely secure, but reasonable measures are used to protect the data.
